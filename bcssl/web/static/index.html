About this lab

    

      
BCSSL Cybersecurity Assessment Lab is an authorized, local-only
      educational lab. It assesses one deliberately vulnerable training application on
      the loopback interface.

      
The target validator refuses public IPs, external domains, arbitrary URLs and
      unauthorized ports before any tool runs. Excluded everywhere: uploads,
      injection, remote file retrieval, denial of service, command execution, SQL
      injection, authentication bypass, remote source inclusion, brute force and fuzzing.

      
Findings are automated indicators. They require manual verification, and an
      empty result is not proof that an application is secure.

      
Command line equivalents of every dashboard action:

      
python -m bcssl preflight
python -m bcssl validate-target
python -m bcssl run-all
python -m bcssl report --correlation-view
python -m bcssl lab list
python -m bcssl lab progress
